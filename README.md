# Camden CO2 saved scenario data

This branch stores 450 precomputed scenario combinations for the additional Camden CO2 Lab Saved Scenarios app. The catalogue records input ranges, checkpoint hashes, quantization scale and checked storage error. Each stored field was produced with the verified V12 weather and V17 CO2 pipeline over the complete 800 by 800 grid at 16 heights.

The application source is on the main branch under Research/CO2/Camden-CO2-Lab-Saved. sha256.json records the generated file checksums.
