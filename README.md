# Camden PM2.5 saved scenario data

This branch stores 540 valid precomputed scenario combinations for the additional Camden PM2.5 Lab Saved Scenarios app. The catalogue records input ranges, the checkpoint hash, per-field encoding, storage error and grid coordinates. It covers the complete 800 by 800 domain at 12 heights.

The original 5 microgram-per-cubic-metre negative boundary shift is unavailable because it would create negative incoming concentrations. The frontend labels that option as unavailable. sha256.json records the file checksums. The application source is on main under Research/Pollutants/Camden-PM25-Lab-Saved.
