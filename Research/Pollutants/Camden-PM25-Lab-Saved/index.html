About the baseline, reference and PALM 6 September 2019 · 02:00 UTC · hourly mean

The baseline is the surrogate prediction with unchanged inputs: 100% emissions, 100% wind speed, 0° rotation and no incoming PM₂.₅ shift. PALM is the separate physical simulation used to assess that prediction. The incoming concentration profile is a boundary input, separate from the baseline.

Scenario change means scenario minus baseline. The PALM comparison covers the original held-out reference case; altered scenarios are sensitivity experiments.

The 8 × 8 km model grid contains the entire Camden boundary. Maps and statistics show valid atmospheric cells inside Camden at the chosen fixed model height. Excluded cells below terrain or inside buildings do not indicate a truncated domain. The PALM framework is described by Maronga et al. (2020); see also the related London PALM-CO₂ study by Li et al. (2026). Both the current and previous-hour drivers receive the same scenario adjustments. This PM₂.₅ model uses a full-domain prediction; tile selection is not provided.

Each available combination loads a result generated beforehand with the verified PM2.5 surrogate over the original full domain. The baseline uses reference inputs. Scenario maps are labelled with the settings of the loaded result. The saved fields are stored with a checked error of at most 0.001 µg/m³.

Scenario controls modify model inputs in physical units. Previous atmospheric states and temporal features follow the supplied model workflow. Changing viewing height or selecting a location uses the already computed field.

All 12 supplied model heights are available. A level with no valid atmospheric cells is shown as empty. Concentration colours are clipped for visibility; errors and changes remain signed and all numeric metrics use the unmodified fields.
