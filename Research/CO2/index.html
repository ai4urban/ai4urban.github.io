Camden CO₂ Lab

Explore how emissions, wind speed, wind direction and boundary CO₂ affect predicted concentrations across Camden.

Each run maps 30-minute average CO₂ concentrations on a 10 m grid at 16 heights. Choose one of ten tiles or the whole 8 × 8 km model domain. For example, set emissions to 80% of the reference value and see where concentrations change compared with the baseline.

Run a prediction

The model runs in your browser. Start with a tile for a faster result. Whole-domain predictions and runs with custom weather can take several minutes.

Example prediction

This example uses 80% of reference emissions and reference weather. The maps show concentrations at 45 m, and the profiles show how concentrations vary with height at the selected location.
