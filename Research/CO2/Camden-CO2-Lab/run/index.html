About this demonstration

The browser applies the Camden CO₂ surrogate using prepared meteorology for saved settings or computes new meteorology for custom settings. The PALM simulation supplies a reference for the original inputs. Tiles overlap and can predict different values at the same location. Choose Whole domain for a single calculation over the full grid. The maps show atmospheric cells inside Camden.

Boundary data comes from the ONS Local Authority Districts, May 2024 (20 m generalised). Contains OS and ONS data.
